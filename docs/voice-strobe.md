# 语音频闪

NexBox 的语音频闪功能,让麦克风输入转化为屏幕闪烁效果,常用于游戏内外的可视化反馈场景。

## 功能特性

- **麦克风驱动**:实时采集麦克风音量,音量高低驱动闪烁强度。
- **多设备支持**:自动枚举本机音频输入设备,可自由切换。
- **可调参数**:灵敏度、触发阈值、平滑度等均可按需配置,避免误触发。
- **轻量无感**:常驻后台运行,占用极低,不影响游戏帧率。

## 使用方式

1. 进入「语音频闪」页面;
2. 选择目标音频输入设备;
3. 调整灵敏度与阈值;
4. 开启频闪开关即可生效。

## 常见问题

- **没有反应**:请确认已选择正确的输入设备,并适当调低触发阈值。
- **闪烁过强**:降低灵敏度或调低最大亮度,可减少干扰。
