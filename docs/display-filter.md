# 显示滤镜

NexBox 的显示滤镜功能,通过系统级 gamma/ICC 校色手段,让你的屏幕呈现出更合适的观感。

## 功能特性

- **色温调节**:一键切换暖色 / 冷色模式,长时间使用更护眼。
- **亮度与对比度**:独立调节亮度、对比度与饱和度。
- **多显示器支持**:每个显示器独立设置,互不干扰。
- **预设组合**:支持多套滤镜叠加组合,按场景快速切换。
- **精确恢复**:退出时按捕获的原始 gamma 数据精确还原,不会破坏系统校色。

## 使用方式

1. 进入「显示滤镜」页面;
2. 选择目标显示器;
3. 调整色温、亮度等参数;
4. 启用后即时生效。

## 说明

- 滤镜通过硬件 gamma ramp 落屏,对游戏帧率无影响。
- 支持搭配游戏自动滤镜使用,互不冲突。
