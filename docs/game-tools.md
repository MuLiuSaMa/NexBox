# 游戏工具箱

NexBox 游戏工具箱汇集了一系列为游戏场景打造的实用小工具,一站式解决游戏内外的高频需求。

## 功能模块

- **战绩统计**:查看《三角洲行动》等游戏的实时战绩数据。
- **显示滤镜**:调节屏幕色温与亮度,优化游戏画面观感。
- **语音频闪**:让麦克风输入转化为可视化闪烁反馈。
- **悬浮窗**:常驻置顶显示 FPS 与网络状态。
- **系统优化**:存储清理、内存清理等让电脑保持最佳状态。

## 特点

- **开箱即用**:无需繁琐配置,进入即可使用。
- **本地优先**:所有数据与处理都在本机完成,注重隐私与安全。
- **相互配合**:各功能模块协同工作,例如显示滤镜可与游戏自动滤镜叠加使用。

## 使用方式

在工具箱主界面选择对应功能入口,即可进入相应模块。
