# 存储清理

NexBox 的存储清理功能,帮助你在不破坏系统与常用软件的前提下,安全释放磁盘空间。

## 功能特性

- **精准扫描**:按文件与目录维度扫描常见缓存、临时文件与冗余数据。
- **分类展示**:按清理项分类汇总占用空间,一目了然。
- **安全删除**:内置删除引擎带校验与失败重试,避免误删与残留。
- **可选择性**:逐项勾选要清理的内容,完全由你掌控。

## 使用方式

1. 进入「存储清理」页面;
2. 点击扫描,等待结果生成;
3. 勾选需要清理的项;
4. 点击清理并等待完成。

## 说明

- 清理前请确认相关应用已退出,以免文件被占用导致清理不完整。
- 建议定期清理,保持系统运行流畅。
