# 内存清理

NexBox 的内存清理功能,通过一键整理系统内存占用,让长时间运行或大游戏后的电脑恢复流畅。

## 功能特性

- **一键释放**:快速整理可用内存,缓解卡顿。
- **进程识别**:只清理可安全回收的缓存与空闲内存,不误伤正在使用的程序。
- **状态展示**:清晰显示清理前后的内存占用变化。
- **低风险**:不结束任何用户进程,安全可控。

## 使用方式

1. 进入「内存清理」页面;
2. 查看当前内存占用概览;
3. 点击一键清理;
4. 观察清理前后对比。

## 说明

- 清理效果受系统状态影响,内存本身由操作系统动态管理,如遇明显不足建议搭配存储清理使用。
- 该功能不替代硬件升级,主要用于临时缓解占用压力。
