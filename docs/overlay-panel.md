# 悬浮窗

NexBox 的悬浮窗是一组常驻桌面顶层的轻量小窗,让你在游戏或全屏应用中也能随时查看状态信息。

## 功能特性

- **置顶显示**:窗口始终悬浮于桌面最上层,不遮挡操作。
- **实时数据**:支持显示 FPS、延迟、网络状态等运行指标,信息随到随更。
- **两种形态**:横排与竖排两种悬浮布局,适配不同屏幕与习惯。
- **低干扰设计**:半透明、可缩放,视觉上不抢焦点。

## 使用方式

1. 进入「悬浮窗」页面;
2. 选择横排或竖排布局;
3. 勾选要展示的指标项;
4. 开启后即可在桌面上看到悬浮窗。

## 说明

- 悬浮窗为独立进程窗口,关闭主界面后仍可保持显示。
- 可随时回到页面调整样式与显示内容。
